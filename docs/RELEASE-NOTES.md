Still 2.6.1 adds the fonts for the Spaced look.

- **Bundled fonts:** Still now includes **Quicksand** and **Michroma**, both under the SIL Open Font License, on Windows and Linux. They appear at the top of the font lists.
- **Spaced preset:** the weekday uses **Anurati** if it's installed on your computer, the font of the popular "Mond" desktop skin. Anurati is free for personal use, so Still doesn't include it. Without it, Still uses the bundled Michroma, a similar wide display font. The date and time now use Quicksand.
- **Small text font:** a new setting on the Style page picks a separate font for the Spaced date and time lines. It defaults to the main font for every other preset.

Existing preferences are kept. Choose the Spaced preset again to pick up the new fonts.

Windows: if Still 2.5 or later is installed, open About and press Check for updates. Otherwise download Still-Setup-win-x64.exe, exit the old Still from its notification-area icon, and run Setup.

Linux: download Still-linux-x64.tar.gz, then run: tar -xzf Still-linux-x64.tar.gz && cd Still-linux-x64 && ./install.sh

The downloads are unsigned. SHA256SUMS.txt contains the checksums of all three.
