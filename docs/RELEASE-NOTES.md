Still 1.1.0 adds a Windows installer and a simpler futuristic settings interface.

- Minimal uses a transparent clock background.
- Type uses a solid dark card.
- Glass uses a translucent card with coral time text.
- The Desktop tab is removed; position and startup controls are under Advanced.
- Drag the clock to move it, or double-click to open Settings.

Install: download Still-Setup-win-x64.exe, exit the old Still from its notification-area icon, and run Setup. The installer installs for your Windows user without administrator access and includes .NET. A portable Still-win-x64.zip is also available. Existing preferences are kept.

The installer is unsigned. SHA256SUMS.txt contains the checksums of both downloads.
