Still 2.5.2 fixes the clock freezing at login.

- The clock now keeps time from the moment it starts. Previously, when Still launched at login without opening Settings, it stayed on the login time until it was clicked.

Existing preferences are preserved.

Windows: download Still-Setup-win-x64.exe or use Check for updates in an installed copy. A portable Still-win-x64.zip is also available.

Linux: download Still-linux-x64.tar.gz, extract it and run ./install.sh.

SHA256SUMS.txt contains checksums for all three downloads.
