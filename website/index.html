// 01 PRESETS

Sixteen starting points.

Every preset is only a starting point. Change any colour, font, layout or effect afterwards. These are actual renders exported from the app.

The backdrop behind each clock is illustrative.

// 02 FEATURES

A settings studio, not a config file.

Five pages, a live preview and instant saving. Basic customization never needs markup.

01

Theme

A live gallery of all sixteen presets, one-click palettes (Cyber, Synth, Matrix, Solar, Plasma, Ice, Ember, Classic) and Dark, Light or Match system settings.

02

Style

Classic, Poster, Script, Overlay, Arc, Split, Spaced or Flip. Fonts, weight, spacing, hex colours, 12/24-hour, seconds, date formats, scale and opacity.

03

Effects

Neon glow, gradient text, seconds indicators, blinking separators, frames, captions, time-zone tags, glass surfaces, corner radius and CRT scanlines.

04

Calendar

An optional Month, Week or Strip calendar below or beside the clock, with week numbers, dimmed weekends and today marked in your accent colour.

05

Advanced

Lock, click-through, always-on-top, launch at sign-in, per-display placement and a safe custom text template with placeholders like {time}.

↔

Theme sharing

Copy theme puts a single still-theme: line on your clipboard. Paste it on another PC, on Windows or Linux, to carry the look across.

// 03 PRINCIPLES

Quiet by design.

Native, not a web view

C# on .NET 10 LTS. WPF on Windows, Avalonia on Linux, one shared core. No browser engine running on your desktop.

Nothing phones home

No server, account, telemetry or background network use. Still only contacts GitHub when you press Check for updates.

No elevated privileges

Installs for your user only. No administrator or root rights, ever. Preferences stay in a single local JSON file.

Accurate and light

Reads the system clock on every refresh instead of counting. Ticks per minute unless seconds are visible, and not at all when hidden.

Verified updates

On Windows, updates are checked against the release's published SHA-256 checksums before Setup runs.

Open source

Every line is on GitHub under the MIT licence. Read it, build it, fork it.

// 04 INSTALL

Running in under a minute.

  1. 01

    Download Setup

    Get Still-Setup-win-x64.exe from the latest release. The installer includes .NET.

  2. 02

    Run it

    Still installs for your Windows user with a Start menu shortcut. No administrator rights needed. If an older Still is running, exit it from its tray icon first.

  3. 03

    Pick a preset

    Launch Still and choose a look such as Neon, HUD, Holo or Flip. Drag the clock to move it; double-click it to open Settings.

Targets Intel/AMD x64 Windows 11. Prefer no installer? Extract the portable ZIP to a permanent folder and run Still.exe. The release is unsigned; checksums are in SHA256SUMS.txt.

  1. 01

    Download

    Get Still-linux-x64.tar.gz, a single self-contained executable with .NET included.

  2. 02

    Install for your user

    $ tar -xzf Still-linux-x64.tar.gz
$ cd Still-linux-x64
$ ./install.sh

    No root. Installs to ~/.local/opt/still, adds a still command and a menu entry, and starts at login (use --no-autostart to skip).

  3. 03

    Enjoy

    Tested on Arch Linux with KDE Plasma 6 (Wayland). Works on any compositing X11 or Wayland desktop. GNOME needs the AppIndicator extension for the tray icon.

To remove Still, run ~/.local/opt/still/uninstall.sh (add --purge to delete your settings too).
